Installation & Setup

System Requirements

  • OS: Windows 10 or Windows 11 (64-bit)
  • RAM: Minimum 4GB (8GB recommended)
  • Storage: 500MB for application + database
  • Internet: Not required (fully offline)

Installation Steps

1

Download Installer

Download SchoolManagementSystem_Setup.exe from the dist folder

2

Run Setup

Double-click the installer and follow the setup wizard

3

Choose Location

Accept default or select custom installation path in Program Files

4

Create Shortcuts

Select to create Desktop and Start Menu shortcuts (recommended)

5

Launch App

Click "Launch" to start the application after installation

6

First Run

Application initializes database and creates required directories

Portable Installation (No Installer)

Alternatively, extract SchoolManagementSystem_Portable.zip to any folder and run SchoolManagementSystem.exe directly.

✓ Installation Complete – The application is ready to use. User data is stored in %LOCALAPPDATA%\SchoolManagementSystem\

Getting Started

First-Time Setup

  1. Launch Application – Click the desktop shortcut or Start Menu entry
  2. Initialize Database – The app automatically creates the database on first run
  3. View Dashboard – You'll see the main dashboard with statistics

Core Workflows

📋 Student Registry

  1. Navigate to the Student Registry tab
  2. Click "+ Add Student" to add new students
  3. Fill in student details:
    • Admission Number (required, unique)
    • Full Name, Date of Birth
    • Class and Section assignment
    • Contact information
  4. Save the student record
  5. Use search and filters to find students quickly
  6. Export student list as CSV or PDF

👥 Staff Directory

Manage employee records, designations, contact information, and workload allocation. Staff modules are coming in Phase 2.

📅 Timetable Management

Create and manage class schedules with automatic conflict detection. The system prevents:

  • Teacher double-booking in overlapping periods
  • Classroom conflicts
  • Student section conflicts

📝 Examination Module

Features include:

  • Question bank management by subject and difficulty
  • Automated exam paper generation with variants
  • Marks entry with one-click ranking
  • Automatic report card and tabulation sheet generation

💰 Fee Management

One-click billing system with:

  • Automatic arrears rollover
  • Discount and concession application
  • Sequential invoice numbering
  • 3-part bank challan generation for printing

✓ Attendance Tracking

Fast attendance marking with automatic calculations for absenteeism monitoring.

Database & Data Storage

Data Location

Component Location Description
School Database %LOCALAPPDATA%\SchoolManagementSystem\data\school.db SQLite database with all school records
Backups %LOCALAPPDATA%\SchoolManagementSystem\backups\ Compressed backup files
Reports %USERPROFILE%\Documents\School_Reports\ Exported PDFs and CSV files
Logs %LOCALAPPDATA%\SchoolManagementSystem\logs\ Application logs for troubleshooting

Database Schema

The application uses SQLite with the following main tables:

  • students – Student records with enrollment status
  • guardians – Parent and guardian information
  • staff – Teacher and staff profiles
  • classes – Grade levels and sections
  • attendance – Daily attendance logs
  • fee_structure – Fee configuration per class
  • invoices – Fee billing records
  • timetable – Class schedules
  • questions – Question bank
  • exam_papers – Generated exam papers
  • exam_results – Student marks and grades
  • audit_log – Record of critical operations

Data Backup

  1. Open File → Backup Database
  2. Choose backup location (defaults to Backups folder)
  3. Backup file is compressed and timestamped
  4. To restore: File → Restore Database and select backup file
⚠ Important: Regular backups are recommended. Always maintain an external backup on a USB drive or separate storage device.

Development & Building from Source

Prerequisites

  • Python 3.10 or higher
  • pip (Python package manager)
  • Inno Setup 6 (for installer creation)
  • Git (for version control)

Setup Development Environment

# Clone or extract the project
cd SchoolManagementSystem

# Create virtual environment
python -m venv venv
venv\Scripts\activate  # On Windows

# Install dependencies
pip install -r requirements.txt

Running in Development Mode

# Run the application directly
python src/main.py

# Or with debugging
python -m pdb src/main.py

Building the Executable

# Build .exe and installer
python build_installer.py

# Output:
# - dist/SchoolManagementSystem/SchoolManagementSystem.exe (standalone app)
# - dist/SchoolManagementSystem_Setup.exe (installer)

Troubleshooting

Application won't start

  • Check Windows version: Windows 10 or 11 (64-bit) required
  • Verify permissions: Ensure you have write access to Program Files and %LOCALAPPDATA%
  • Check logs: Review %LOCALAPPDATA%\SchoolManagementSystem\logs\app.log

Database errors

  • Database locked: Close other instances and restart the application
  • Permission denied: Ensure %LOCALAPPDATA% is accessible and writable
  • Corrupted database: Restore from backup and verify file integrity

UI issues

  • Blurry text: Enable High DPI scaling in Windows display settings
  • Missing features: Verify user role has appropriate permissions
  • Slow performance: Check available disk space and close other applications

Data issues

  • Missing students: Check filters and search box – they may be hidden
  • Duplicate records: Use unique admission numbers and verify during entry
  • Lost data: Restore from backup using File → Restore Database
