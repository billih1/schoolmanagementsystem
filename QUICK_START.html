Quick Start Guide - Run the Application

✨ Choose Your Method

Select the easiest way to run the application on your computer:

1 Easiest: Double-Click run.bat

Perfect for Windows users who want the simplest method:

  1. Navigate to: C:\Users\Ali\SchoolManagementSystem
  2. Find the file: run.bat
  3. Double-click it
  4. Wait for the application window to open

What happens:

  • Command window opens briefly
  • Virtual environment activates
  • Application initializes (you'll see messages)
  • School Management System GUI window appears
  • Ready to use! 🎉
✓ Recommended for most users — No typing required, just double-click
2 Alternative: PowerShell Script

If you prefer using PowerShell:

cd C:\Users\Ali\SchoolManagementSystem .\run.ps1

Note: You may need to allow script execution first:

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
3 Manual: PowerShell Commands

If you want to run commands manually:

cd C:\Users\Ali\SchoolManagementSystem .\venv\Scripts\Activate.ps1 python src/main.py

This approach gives you full control and shows all output messages.

🔧 Troubleshooting

❌ "run.bat not found"

Make sure you're in the correct directory: C:\Users\Ali\SchoolManagementSystem

❌ "ModuleNotFoundError: No module named 'PyQt6'"

Dependencies haven't been installed. Run this in PowerShell:

cd C:\Users\Ali\SchoolManagementSystem python -m venv venv .\venv\Scripts\Activate.ps1 pip install -r requirements.txt

❌ "venv not found"

Create the virtual environment:

python -m venv venv

❌ Application window doesn't appear

Check the command window for error messages. Common causes:

  • Database directory cannot be created (permissions issue)
  • PyQt6 not properly installed
  • Display settings issue (try restarting)

📊 What Happens When You Start

First Time

  1. Application creates database directory: %LOCALAPPDATA%\SchoolManagementSystem\
  2. Initializes SQLite database: school.db
  3. Creates required tables automatically
  4. Opens the graphical user interface
  5. You're ready to use the system!

Subsequent Times

  1. Application loads existing database
  2. All your data is preserved
  3. Ready to continue working
