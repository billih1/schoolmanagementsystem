How to Run It on Your Computer

✨ All Fixed & Ready!

Pick your preferred method below to start the application.

1
EASIEST: Double-Click run.bat
👉 Recommended for everyone
  1. Navigate to: C:\Users\Ali\SchoolManagementSystem
  2. Find the file: run.bat
  3. Double-click it
  4. Wait for the application window to appear
✓ That's it! The app opens. Database initializes on first run. Your data persists between sessions.
2
PowerShell Script
If you prefer using PowerShell
cd C:\Users\Ali\SchoolManagementSystem .\run.ps1

If you get a script execution error, run this first:

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
3
Manual PowerShell Commands
Full control version
cd C:\Users\Ali\SchoolManagementSystem .\venv\Scripts\Activate.ps1 python src/main.py

This shows all messages and gives you full control.

🎯 What Happens When You Run It

First Time:

  • Command window appears briefly
  • Virtual environment activates
  • Database initializes at %LOCALAPPDATA%\SchoolManagementSystem\data\school.db
  • GUI window opens with the Student Registry
  • Ready to add students and use features!

Next Times:

  • Just run the same command again
  • All your data is preserved
  • Instantly ready to use

🔧 Troubleshooting

❌ "File not found" or "Command not recognized"

Make sure you're in the correct directory: C:\Users\Ali\SchoolManagementSystem

❌ Application window doesn't appear

Check the command window for error messages. Common cause: PyQt6 module not found. If this happens, run: pip install -r requirements.txt

❌ Port already in use or database locked

Close other instances of the application and try again.
